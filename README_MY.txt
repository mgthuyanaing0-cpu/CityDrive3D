CITY DRIVE ANDROID PROJECT

ပါဝင်သောအရာများ
- ကား ၃ မျိုးရွေးချယ်နိုင်ခြင်း
- ကားမောင်းခလုတ်များ၊ CAM
- CAR/WALK လမ်းလျှောက် mode
- မြို့၊ traffic ကားများ၊ လူဇာတ်ကောင်များ
- minimap နှင့် checkpoint mission
- Android WebView wrapper; game runs offline

သတိ: ဒီ ZIP က Android Studio project source ဖြစ်ပြီး APK ဖိုင်ကို compile လုပ်ပြီးသားမဟုတ်ပါ။
APK ထုတ်ရန် Android Studio ကို ကွန်ပျူတာတွင်ဖွင့်ပြီး ဒီ folder ကို Open လုပ်ပါ။
ပြီးလျှင် Build > Build APK(s) ကိုနှိပ်ပါ။ Android SDK/Gradle setup လိုအပ်ပါမည်။
Browser စမ်းချင်လျှင် app/src/main/assets/index.html ကိုဖွင့်ပါ။
